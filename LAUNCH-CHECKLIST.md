# Checklist for Course Launch

## Pre-Launch Setup

- [ ] Update `config.toml` with:
  - [ ] Your name and email
  - [ ] Correct GitHub repository URL
  - [ ] Base URL for GitHub Pages
  - [ ] Course term/semester

- [ ] Customize content:
  - [ ] Update syllabus with actual dates, policies
  - [ ] Add real reading materials
  - [ ] Add your actual assignment descriptions
  - [ ] Update contact information and office hours
  - [ ] Add course resources and links

- [ ] Make scripts executable:
  ```bash
  chmod +x scripts/*.sh
  ```

## GitHub Setup

- [ ] Create GitHub repository: `ai-and-society`
- [ ] Clone locally if not already done
- [ ] Add initial content
- [ ] Push to GitHub:
  ```bash
  git add .
  git commit -m "Initial course site"
  git push -u origin main
  ```

- [ ] Enable GitHub Pages in Settings:
  - [ ] Go to Settings > Pages
  - [ ] Source: Deploy from a branch
  - [ ] Branch: main (or master)
  - [ ] Directory: / (root)

- [ ] Wait for first deploy (~2 minutes)
- [ ] Visit: `https://yourusername.github.io/ai-and-society/`

## Brightspace Integration

### Option 1: Link to Public Site
- [ ] Go to course content
- [ ] Add external link pointing to course website
- [ ] Test link works for students

### Option 2: Upload Documents
- [ ] Run: `bash scripts/convert-to-formats.sh`
- [ ] Review output files
- [ ] Upload .docx files to D2L content library
- [ ] Create links to content library in course modules

### Option 3: Embed Website
- [ ] D2L: Add Learning Tool > External
- [ ] Configure to embed course website
- [ ] Test embedded view

## Accessibility Verification

- [ ] Test with keyboard navigation
  - [ ] Tab through all links and buttons
  - [ ] Can navigate entire site without mouse

- [ ] Check with screen reader
  - [ ] Use browser extension (NVDA, JAWS, VoiceOver)
  - [ ] Test heading structure
  - [ ] Verify alt text on images

- [ ] Test with accessibility checker
  - [ ] Use: axe DevTools or WAVE browser extensions
  - [ ] Fix any errors

- [ ] Test color contrast
  - [ ] Use: Contrast Checker tool
  - [ ] Ensure WCAG AA compliance (4.5:1 ratio)

- [ ] Test PDF accessibility
  - [ ] Open PDFs generated by Pandoc
  - [ ] Check with PDF accessibility checker
  - [ ] Verify text is tagged

## Course Content Verification

- [ ] All links work
- [ ] All readings appear correctly
- [ ] All assignments are clear and complete
- [ ] Rubrics are visible and make sense
- [ ] Examples load properly (if embedded)
- [ ] Mobile view looks good
  - [ ] Test on phone/tablet
  - [ ] Navigation works on mobile

## Testing Conversions

- [ ] Generate PDF/Word versions:
  ```bash
  bash scripts/convert-to-formats.sh
  ```

- [ ] Open converted files and verify:
  - [ ] Content is complete
  - [ ] Formatting looks correct
  - [ ] Images included (if any)
  - [ ] Headers and structure intact
  - [ ] Hyperlinks work in PDFs

## Pre-Semester Communication

- [ ] Email to students:
  - [ ] Where to find course materials
  - [ ] How to access readings (web vs download)
  - [ ] D2L vs. public website (explain integration)
  - [ ] Technical support contacts
  - [ ] Accessibility support options

- [ ] Create D2L announcement with:
  - [ ] Course website URL
  - [ ] How to use website effectively
  - [ ] Download options for offline reading
  - [ ] Feedback/issue reporting process

## During Semester

- [ ] Monitor for dead links
- [ ] Update readings/resources as needed
- [ ] Regenerate PDFs/Word docs when content changes:
  ```bash
  bash scripts/convert-to-formats.sh
  ```

- [ ] Update D2L with new documents
- [ ] Gather student feedback on site usability
- [ ] Make improvements based on feedback

## Emergency Procedures

### Site Goes Down
- [ ] Check GitHub Pages status
- [ ] Verify domain is configured correctly
- [ ] Communicate to students via D2L
- [ ] Provide documents as backup

### Content Issues
- [ ] Quick fix in GitHub
- [ ] Push to main branch
- [ ] Deploy happens automatically (~2 min)
- [ ] Test fix is live

### Accessibility Issue Reported
- [ ] Fix in markdown/config
- [ ] Push to GitHub
- [ ] Re-generate PDFs if needed
- [ ] Respond to student with timeline
