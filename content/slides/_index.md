# Slides

Every lecture deck is here in two forms.

- **Present** opens the deck full-screen in your browser. Use the arrow keys or
  space bar to move between slides, `f` for fullscreen, and `p` for presenter
  view with speaker notes.
- **PDF** downloads the same deck as a file. This is the version posted to D2L,
  so you do not need both.

Decks are posted after each class meeting. If a lecture is missing, it has not
been given yet.
